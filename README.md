# Finans Takip

Basit, yerel depolamalı (localStorage) gelir/gider takip uygulaması. React, TypeScript, Vite, Tailwind CSS v4 ve Recharts ile geliştirildi.

## Özellikler

- Gelir ve gider işlemleri ekleme, silme
- Kategoriye göre işlem sınıflandırma
- Bakiye, toplam gelir ve toplam gider özeti
- Kategoriye göre gider dağılımı (pasta grafik)
- Aylık gelir/gider trendi (bar grafik)
- İşlem arama ve türe göre filtreleme
- Veriler tarayıcının localStorage'ında saklanır

## Geliştirme

```bash
npm install
npm run dev
```

## Derleme

```bash
npm run build
```
